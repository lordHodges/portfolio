# Directrices de Desarrollo y Convenciones

## Convención de Commits de Git
- **Formato obligatorio**: Conventional Commits (`feat:`, `fix:`, `chore:`, `refactor:`, `docs:`, `test:`, `style:`).
- **Idioma**: Español.
- **Tono y estilo**: Lenguaje alegre, entusiasta y positivo, pero a la vez muy descriptivo, claro y técnicamente preciso.
- **Ejemplos de referencia**:
  - `feat: ¡incorporado el catálogo de proyectos con filtros reactivos y diseño neo-brutalist genial!`
  - `fix: solucionado el enlace de descarga directa del CV para entregar el PDF al instante 🚀`
  - `docs: actualizada la documentación técnica de arquitectura con diagramas claros`
